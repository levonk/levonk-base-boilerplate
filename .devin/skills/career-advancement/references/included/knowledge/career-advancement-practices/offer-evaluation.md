# Offer Evaluation

## Total Compensation

An offer is not a salary — it is a **package**. Evaluating an offer means
calculating **total compensation**, which is the sum of every component with
monetary value across a year. Focusing only on base salary is the most
common mistake candidates make, and it can mean leaving significant money on
the table — or accepting an offer that looks strong but is structurally weak.

### The Components

| Component | Type | Notes |
|-----------|------|-------|
| **Base salary** | Cash, guaranteed | The foundation. Capped by the salary band. |
| **Equity** | Variable, illiquid | RSUs, ISOs, or NSOs. Value depends on vesting, cliff, and liquidity. |
| **Signing bonus** | Cash, one-time | Often negotiable. Paid at start or split across milestones. |
| **Annual bonus** | Cash, variable | Has a target percentage; may or may not be guaranteed. |
| **Benefits** | Non-cash value | Health, 401k match, PTO, parental leave. Real dollar value. |
| **Intangibles** | Non-monetary | Remote policy, growth trajectory, tech stack, manager quality. |

## Equity

Equity is the component most likely to be misunderstood and the most
variable in actual value. The type of equity, the vesting schedule, and the
exercise terms all determine whether the equity is worth anything at all.

### Equity Types

| Type | Full name | Tax treatment | When granted |
|------|-----------|--------------|-------------|
| **RSU** | Restricted Stock Unit | Taxed as ordinary income at vest | Public companies, late-stage startups |
| **ISO** | Incentive Stock Option | Potential AMT preference; favorable if held | Early-stage startups (private) |
| **NSO** | Non-Qualified Stock Option | Taxed as ordinary income at exercise | Later-stage startups, non-employees |

### Vesting Schedules

**Vesting** is the process by which you earn your equity over time. You do
not receive it all upfront.

| Schedule | Structure | Notes |
|----------|-----------|-------|
| **4-year vest, 1-year cliff** | Industry standard | Nothing vests for the first year; then 25% vests, followed by monthly or quarterly vesting |
| **3-year vest** | Becoming more common | Faster vesting but smaller annual amounts |
| **Back-loaded vesting** | Increases in later years | Red flag — designed to make leaving expensive |
| **Cliff-only** | All or nothing at cliff | Rare; high-risk for the employee |

### Key Equity Terms

- **Cliff** — The period before any equity vests (typically 1 year). If you
  leave before the cliff, you get nothing.
- **Exercise window** — How long you have to exercise vested options after
  leaving the company. Standard is 90 days; some companies now offer longer
  windows (1–10 years). A 90-day window can force you to exercise options
  you cannot afford, or lose them.
- **Acceleration clauses** — Provisions that cause vesting to accelerate on
  certain events. **Single-trigger** accelerates on acquisition alone;
  **double-trigger** requires acquisition *and* termination within a window.
  Double-trigger is more common and more employee-friendly.

## Signing Bonus and Annual Bonus

### Signing Bonus

A **signing bonus** is a one-time cash payment, usually offered to offset
the loss of unvested equity at your current employer or to bridge a gap
when the base salary is capped by the band. It is often the most negotiable
component of an offer.

### Annual Bonus

| Aspect | What to ask |
|--------|------------|
| **Target** | "What is the target bonus percentage for this level?" |
| **Guaranteed vs variable** | "Is there a guaranteed minimum, or is the full amount discretionary?" |
| **Historical payout** | "What has the company paid out historically — at target, above, or below?" |
| **Timing** | "When is the bonus paid, and am I eligible in year one?" |

A "target bonus" of 15% that historically pays out at 100% is worth more
than a "target bonus" of 20% that historically pays out at 60%. Always ask
for historical payout data.

## Benefits

Benefits have real dollar value and should be factored into total
compensation.

| Benefit | What to evaluate |
|---------|-----------------|
| **Health insurance** | Premiums, deductibles, out-of-pocket max. A $500/month premium difference is $6,000/year. |
| **401k match** | Match percentage and vesting schedule on the match. |
| **PTO** | Days per year, whether it includes sick leave, and whether unused days roll over or are paid out. |
| **Parental leave** | Primary vs secondary caregiver leave; paid vs unpaid; tenure requirements. |
| **Other** | Commuter benefits, FSA/HSA, wellness stipends, learning budgets. |

## Intangibles

Intangibles are non-monetary but have enormous impact on career trajectory
and daily quality of life.

- **Remote policy** — Is it fully remote, hybrid, or on-site? Is the policy
  stable or in flux?
- **Growth trajectory** — Is the team growing? Is there a clear path to the
  next level?
- **Tech stack** — Will you be working with modern tools that increase your
  market value, or a legacy stack that narrows your future options?
- **Manager quality** — Your manager is the single biggest factor in job
  satisfaction. If you met them in the interview, trust that read.

## The Offer Comparison Matrix

When evaluating multiple offers, build a **comparison matrix** so you can
see the full picture side by side rather than comparing one component at a
time.

| Component | Offer A | Offer B | Offer C |
|-----------|---------|---------|---------|
| Base salary | | | |
| Signing bonus | | | |
| Annual bonus (target) | | | |
| Equity (annualized value) | | | |
| 401k match (value) | | | |
| Health (premium delta) | | | |
| PTO (days) | | | |
| Remote policy | | | |
| Growth trajectory | | | |
| Manager quality | | | |
| **Total estimated comp (year 1)** | | | |

Annualize equity by dividing the grant by the vesting years. For options,
use the strike price and a reasonable valuation — do not assume the
optimistic case.

## Red Flags in Offers

| Red flag | What it signals |
|----------|----------------|
| **Vague equity** ("you'll get a meaningful grant") | No written number means no commitment. Never accept an offer without a specific equity grant in writing. |
| **No written offer** | A verbal offer is not an offer. Do not resign from your current job without a signed written offer. |
| **Pressure to decide immediately** | "We need an answer by end of day" is a tactic to prevent you from comparing offers or negotiating. A reasonable deadline is 3–5 business days. |
| **Exploding offer with a short fuse** | Same as above. If the deadline is under 48 hours, ask for more time. If they refuse, that is a signal about how they treat employees. |
| **Back-loaded vesting** | Designed to make leaving expensive. Standard is even or front-loaded. |
| **90-day exercise window with no extension** | Standard but worth flagging — you can lose vested options if you leave and cannot afford to exercise. |
| **"We'll figure out the level after you start"** | The level determines the band. Without a level, you have no compensation framework. |
| **Bonus with no target or historical data** | A bonus with no target is a bonus that may not exist. |
