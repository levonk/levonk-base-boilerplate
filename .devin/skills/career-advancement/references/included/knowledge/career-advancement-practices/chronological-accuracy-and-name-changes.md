# Chronological Accuracy and Name Changes

## The Problem

Companies get acquired, rebranded, and renamed. Products change names.
Technologies are rebranded. A resume spanning 15+ years will reference
entities that no longer exist under their original name — or that exist under
a name the current audience won't recognize.

Two failure modes:

1. **Using a historical name in a modern document** — The reader doesn't
   recognize the company and discounts the experience.
2. **Using a modern name in a historical context** — The reader catches the
   anachronism and questions the candidate's credibility.

## The Core Rules

### Rule 1: Existence at Time of Employment

Every regulation, technology, product, service, and company referenced in a
resume **must have existed and been publicly available during the stated
employment period**.

Never retroactively insert a modern brand name, product, or technology into a
period before its launch or general availability. If a role ended in 2018, do
not reference a service launched in 2020.

### Rule 2: Time-Appropriate Names in the Archive

In the **archive** (the full historical record), use the **time-appropriate
name** as the primary reference, with the modern name in parentheses on first
mention:

> *TrueData (later Datavations)*
> *AdBureau (now Programmatic Partners)*

This preserves historical accuracy while providing the modern name for
cross-referencing.

### Rule 3: Modern Names in Current Documents

In the **working resume and tailored variants**, use **only the modern name**.
The historical name is not mentioned, except where omitting it would create
ambiguity for a modern reader.

Never use a historical name in a modern document unless it is essential for
clarity.

### Rule 4: Technology and Service Name Changes

The same rule applies to laws, regulations, technologies, platforms, and
services that were rebranded or renamed:

- **Archive**: Use the name as it was known at the time, with the modern name
  in parentheses
- **Modern documents**: Use the current name only

## The Recognizability Exception

When the modern name is **obscure to the target audience** but the historical
name contains a **recognizable element**, the historical name **may be
retained** in modern documents.

### When to Apply the Exception

Test the modern name against the target audience (typically US-based
recruiters and hiring managers):

1. **Is the modern name widely recognized?** If yes, use the modern name.
2. **Is the modern name obscure?** If yes, check the historical name.
3. **Does the historical name contain a recognizable element?** If yes, retain
   the historical name.
4. **Is neither name recognizable?** Use the name that provides the most
   context, and add a brief clarifier.

### Example

| Historical Name | Modern Name | Decision | Reason |
|----------------|-------------|----------|--------|
| Vivendi Universal | Vivendi | Keep `Vivendi Universal` | `Vivendi` alone is obscure to US employers; `Universal` anchors recognition (Universal Pictures/Studios/Entertainment) |
| TrueData | Datavations | Use `Datavations` (or omit) | Modern name is recognizable enough in context |
| AdBureau | Programmatic Partners | Use `Programmatic Partners` | Modern name is clearer to current audience |

### Documenting the Exception

When granting an exception, document the rationale:

- What the modern name is
- Why it is obscure to the target audience
- What recognizable element the historical name provides

This prevents future agents or collaborators from "correcting" the name back
to the modern form and losing the recognizability.

## Date and Company Format

### Consistent Date Format

Use **Month YYYY – Month YYYY** consistently across all documents. Never use
"Present" instead of a month — ATS flags this as incomplete.

### Company Name Placement

Include company names on their own line, followed by the title on the next
line (or reverse) — never combine into one bullet. Parsers extract company
and title as separate fields.

### No Unexplained Gaps

Never leave employment gaps unexplained. Use:

- `Independent Consulting` — for consulting periods
- `Strategic Sabbatical` — for intentional breaks
- `Family caregiving responsibilities; now available full-time` — for
  caregiving periods

See [Safe Pair of Hands Positioning](safe-pair-of-hands-positioning.md) —
silence equals risk. Address gaps on the page, not in the interview.
